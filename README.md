## 🚀 Come Installare o Aggiornare

1. Scarica il progetto (tramite **Code → Download ZIP** o dalle **Releases**) ed estrailo in una cartella qualsiasi.
2. Assicurati che **Aniimo sia chiuso**.
3. Fai doppio clic su **`Installa Traduzione ITA.bat`**.
4. Premi **`1`** (oppure **Invio**) per installare o aggiornare la traduzione in meno di 2 secondi.
5. **Avvia Aniimo**: il gioco partirà subito in italiano!

### 🔄 Dopo un aggiornamento di Steam
- Riapri **`Installa Traduzione ITA.bat`** e premi **Invio**: l'installer rileverà la nuova patch e riapplicherà al volo i testi italiani sui nuovi file del gioco.
- Dal menu puoi anche premere **`[3]`** per scaricare direttamente da GitHub l'ultima versione di `traduzione_ita.tsv` senza dover riscaricare tutto il pacchetto.

### ⏪ Come rimuovere la traduzione (Tornare all'Inglese)
- Apri **`Installa Traduzione ITA.bat`**, premi **`2`** (*Ripristina Lingua Originale*) e premi **Invio**: i file originali in inglese vengono ripristinati in 2 secondi senza dover verificare l'integrità dei file su Steam.
